🏏 OverScore — Full-Stack Cricket Scoring Application

A full-stack cricket scoring application designed for complete ball-by-ball match management.

It handles teams, players, playing XI selection, toss, innings, runs, wickets, extras, overs, strike rotation, targets, match results and match history.

The application uses an append-only event-based architecture, enabling reliable score calculation, statistics, commentary, undo/redo and historical ball editing.

Tech: React • Python • FastAPI • PostgreSQL • REST APIs
