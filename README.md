## 💼 Workfolio

**Post Work. Find Work. Get It Done.**

Workfolio is a flexible temporary job marketplace where anyone can post work and anyone can find work. It connects people for both technical and non-technical tasks, allowing users to switch between job requester and worker roles.

**Tech:** React • Python • FastAPI

<a href="https://github.com/gundatejeswararao7/Workfolio">View Project →</a>

## 🏏 OverScore — Full-Stack Cricket Scoring Application

A full-stack cricket scoring application designed for complete **ball-by-ball match management**.

It handles teams, players, playing XI selection, toss, innings, runs, wickets, extras, overs, strike rotation, targets, match results and match history.

The application uses an **append-only event-based architecture**, enabling reliable score calculation, statistics, commentary, undo/redo and historical ball editing.

**Tech:** React • Python • FastAPI • PostgreSQL • REST APIs

<a href="https://github.com/gundatejeswararao7/Cricket">View Project →</a>

## ⚡ EcoVolt — Secure IoT Smart Energy Meter

An IoT-powered smart energy monitoring and billing system designed to track electricity consumption in real time, analyze usage patterns, control electrical loads and provide energy insights through a web dashboard.

**Tech:** ESP32 • IoT • Arduino IDE • React • Node.js • Express.js • MongoDB

<a href="https://github.com/gundatejeswararao7/EcoVolt-Smart-Sustainable-Energy">View Project →</a>

## 🕶️ ShadowChat
